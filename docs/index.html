Phillap (AVA)

A local-first personal life assistant for Windows. Your data stays on your PC.

Download for Windows (.zip)

Install

  1. Install Python 3.10 or newer if you do not have it.
  2. Unzip the download anywhere.
  3. Double-click Start-Phillap.bat. Phillap opens in your browser at http://127.0.0.1:8765.

Phillap does not bundle Python. Data is stored in %LOCALAPPDATA%\Phillap, is not encrypted, and is not synced. Daily local backups are kept there.

The download link works once a release named Phillap.zip has been published on GitHub.
